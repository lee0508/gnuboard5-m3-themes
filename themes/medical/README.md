# ONCARE 의료기관 반응형 테마

그누보드5 기반 치과·피부과·성형외과 공통 의료기관 홈페이지 테마입니다.
Pretendard 글꼴과 Boxicons v3 아이콘을 테마 안에 담아 외부 CDN 없이 동작하며, PC·태블릿·모바일에 하나의 반응형 화면을 제공합니다.
색·글자·모서리는 Material Design 3 토큰(`css/m3-tokens.css`)으로 정합니다.

## 설치

1. 이 `medical` 폴더를 그누보드의 `theme/medical` 경로로 복사합니다.
2. 관리자 페이지에서 **환경설정 → 테마설정**으로 이동합니다.
3. `medical` 테마의 **테마적용**을 선택합니다.
4. **환경설정 → 메뉴설정**에서 실제 병원 메뉴와 링크를 등록합니다.

## 운영 전 필수 변경

- `head.php`: 병원명과 로고 텍스트
- `index.php`: 진료과목, 진료시간, 의료진, 예약 링크
- `tail.php`: 주소, 대표전화, 사업자등록번호
- 의료진 이름·경력과 진료 내용은 병원의 최종 검수를 받은 자료로 교체
- 온라인 예약은 현재 그누보드 1:1 문의 페이지로 연결되므로 실제 예약 시스템에 맞게 변경
- `#` 링크는 실제 콘텐츠 페이지 또는 게시판 주소로 변경
- 개인정보처리방침, 민감정보 동의, 의료광고 심의 상태를 오픈 전에 확인

## 글꼴·아이콘·색

- 글꼴: Pretendard (`css/fonts/`, SIL OFL 1.1)
- 아이콘: Boxicons v3 (`css/icons/boxicons-local.css`, MIT). 마크업은 `<i class="bx bx-이름">` 형식이며, 새 아이콘은 `tools/build-boxicons.cjs` 대응표에 더한 뒤 다시 생성합니다.
- 색: `css/m3-tokens.css` 의 `--md-sys-color-*` 토큰. 대표색을 바꾸려면 Material Theme Builder 로 새 값을 만들어 이 파일만 바꿉니다.
- 외부 CDN 을 쓰지 않으므로 사내망·폐쇄망에서도 그대로 동작합니다.
